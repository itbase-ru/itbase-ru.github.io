Асинхронность в Python — asyncio простыми словами

10 апреля 2026 • 11 мин чтения
Поделиться:

Если ты писал на Python что-то, что работает с сетью — парсеры, ботов, веб-сервисы, — скорее всего сталкивался с async и await. Но что за ними стоит, объясняют редко. Разберёмся.

Если ещё не читал про асинхронность в JavaScript — можешь глянуть для сравнения, принципы похожи.

Проблема, которую решает асинхронность

Python выполняет код строка за строкой. Если одна строка «ждёт» (например, скачивает файл из интернета), всё остальное стоит на месте.

import requests

# Скачиваем три файла по очереди
data1 = requests.get('https://site.com/file1').content  # ждём 1 сек
data2 = requests.get('https://site.com/file2').content  # ждём 1 сек
data3 = requests.get('https://site.com/file3').content  # ждём 1 сек
# Итого: 3 секунды

Казалось бы, почему бы не запустить все три запроса одновременно? Потому что в обычном (синхронном) коде нельзя — он ждёт каждый по очереди.

Асинхронность решает это: пока один запрос ждёт ответа, программа делает что-то другое.

Асинхронность — это не про параллельность. Это про то, чтобы не простаивать в ожидании. Пока ждёшь ответ от сети, можешь заняться другим делом.

Синхронный vs асинхронный код

ПодходЧто делает во время ожидания
СинхронныйСтоит и ждёт
АсинхронныйПереключается на другие задачи

Асинхронность хороша, когда много операций ввода-вывода (I/O): сетевые запросы, работа с файлами, база данных. И почти бесполезна, если у тебя тяжёлые вычисления (CPU-bound) — там нужны процессы, а не async.

Ключевые понятия

Event loop

Event loop (цикл событий) — это «дирижёр» асинхронной программы. Он следит за всеми задачами и решает, какую запустить следующей.

Работает так:

  1. Запускает задачу.
  2. Задача доходит до «жду сеть» — говорит event loop: «я подожду».
  3. Event loop переключается на следующую задачу.
  4. Когда приходит ответ — возвращается к первой задаче.

В Python event loop из модуля asyncio. Запускается через asyncio.run().

Корутина (coroutine)

Корутина — это функция, объявленная через async def. Она не выполняется как обычная функция — при вызове она возвращает объект-корутину, который нужно запустить в event loop.

# Обычная функция — выполняется сразу при вызове
def normal():
    return 42

# Корутина — при вызове возвращает объект
async def coro():
    return 42

# Просто вызвать недостаточно — нужно await или запустить в loop
result = coro()   # это не 42, это объект-корутина

await

await говорит: «подожди, пока эта операция завершится, но не блокируй event loop». Ключевое слово используется только внутри async def.

import asyncio

async def main():
    print('Начало')
    # Имитируем запрос — ждём 1 секунду, но не блокируем loop
    await asyncio.sleep(1)
    print('Прошла секунда')

asyncio.run(main())

Первый асинхронный пример

Сравним синхронный и асинхронный код, который делает три «запроса» по секунде.

Синхронный

import time

def fetch(name):
    print(name + ': начал')
    time.sleep(1)              # блокирует всё
    print(name + ': готов')

start = time.time()
fetch('A')
fetch('B')
fetch('C')
print('Всего: ' + str(round(time.time() - start, 2)) + ' сек')
# Всего: около 3 секунд

Асинхронный

import asyncio
import time

async def fetch(name):
    print(name + ': начал')
    await asyncio.sleep(1)     # отдаёт управление loop
    print(name + ': готов')

async def main():
    # Запускаем три задачи одновременно
    await asyncio.gather(
        fetch('A'),
        fetch('B'),
        fetch('C'),
    )

start = time.time()
asyncio.run(main())
print('Всего: ' + str(round(time.time() - start, 2)) + ' сек')
# Всего: около 1 секунды

Разница в три раза. Потому что все три «запроса» шли параллельно, а не по очереди.

asyncio.gather — ключевая функция. Она принимает несколько корутин и запускает их одновременно, дожидаясь всех.

Асинхронные библиотеки

Важно: обычные библиотеки вроде requests не работают с await. Если внутри async-функции вызвать requests.get(), он заблокирует весь event loop, и вся выгода пропадёт.

Нужны асинхронные аналоги:

СинхроннаяАсинхронная
requestsaiohttp, httpx
psycopg2asyncpg
pymongomotor
redisaioredis

Пример с aiohttp:

import aiohttp
import asyncio

async def fetch(url):
    # Клиентская сессия должна быть открыта на всё время работы
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:
            return await response.text()

async def main():
    urls = [
        'https://example.com/1',
        'https://example.com/2',
        'https://example.com/3',
    ]
    # Запускаем все запросы одновременно
    results = await asyncio.gather(
        *[fetch(u) for u in urls]
    )
    print('Получено ответов: ' + str(len(results)))

asyncio.run(main())

Создание задач

Если нужно запустить корутину «в фоне» и не ждать её окончания, используют asyncio.create_task:

async def background_work():
    await asyncio.sleep(5)
    print('Фоновая работа завершена')

async def main():
    # Запускаем в фоне и не ждём
    task = asyncio.create_task(background_work())
    print('Главная функция продолжает работу')
    # ... что-то делаем ...
    await task  # дожидаемся завершения в конце

asyncio.run(main())

Таймауты

Если запрос может зависнуть — задаём лимит времени:

import asyncio

async def slow_operation():
    await asyncio.sleep(10)

async def main():
    try:
        # Если за 3 секунды не выполнится — выбросит TimeoutError
        await asyncio.wait_for(slow_operation(), timeout=3.0)
    except asyncio.TimeoutError:
        print('Не успел за 3 секунды')

asyncio.run(main())

Когда использовать async

Подходит:

  • Много сетевых запросов (парсеры, API-клиенты).
  • Веб-серверы (FastAPI, aiohttp).
  • Telegram-боты (aiogram).
  • Работа с БД под нагрузкой (asyncpg, motor).
  • WebSocket-серверы.

Не подходит:

  • Тяжёлые вычисления (обработка видео, ML).
  • Простые скрипты на 20 строк — оверинжиниринг.
  • Скрипты без I/O — выгоды нет.
Асинхронность ускоряет не любую программу, а только ту, которая много ждёт. Если у тебя код проводит время в вычислениях, а не в ожидании — async не поможет.

Частые ошибки

  • Вызов синхронной библиотеки внутри async-кода. requests или time.sleep заблокируют event loop. Только aiohttp и asyncio.sleep.
  • Забыть await. Функция вернёт объект-корутину, а не результат.
  • Забыть asyncio.run(). Ничего не запустится без него.
  • Не закрыть сессию. aiohttp.ClientSession нужно либо закрывать вручную, либо использовать async with.

Итог

Асинхронность в Python — это способ не простаивать во время ожидания. Ключевые слова: async, await, asyncio.gather. Работает через event loop — «дирижёра», который переключает задачи. Помогает на I/O (сеть, файлы, БД), не помогает на CPU. Использовать только с асинхронными библиотеками.
