Терминал для новичка: 20 команд, которые нужны каждый день

18 февраля 2026 • 9 мин чтения
Поделиться:

Терминал выглядит страшно: чёрное окно, мигающий курсор, никаких кнопок. Но на самом деле это быстрее и удобнее, чем мышкой. Здесь ты пишешь команду — компьютер выполняет.

Зачем вообще терминал

  • Быстрее. «Перейти в папку и запустить сервер» — это две команды вместо десяти кликов.
  • Мощнее. Многие инструменты работают только в терминале: git, docker, npm, ssh.
  • Одинаково везде. На своём компьютере, на сервере, в облаке — те же команды.
  • Автоматизация. Скрипт в терминале делает за минуту то, что руками — час.

Как ориентироваться

Ты всегда находишься «внутри» какой-то папки. Терминал показывает путь перед курсором: ~/projects/site $. Это значит: ты в папке site, внутри projects, внутри домашней папки.

Команда выполняется после нажатия Enter. Если что-то пошло не так — Ctrl+C прерывает.

Полезные трюки

  • Tab — автодополнение имени файла. Набери cd Doc, нажми Tab — терминал допишет остальное.
  • Стрелка вверх — предыдущая команда. Не надо перенабирать.
  • Ctrl+L — очистить экран (или команда clear).
  • Ctrl+C — прервать выполнение. Спасает, когда что-то «зависло».
  • Ctrl+D — выйти из терминала.

Пример: рабочий цикл с Git

Вот как выглядит типичный рабочий процесс программиста в терминале. По шагам:

# 1. Перейти в папку проекта
cd ~/projects/my-site

# 2. Посмотреть, что изменилось
git status

# 3. Добавить все изменения
git add .

# 4. Сохранить с описанием
git commit -m "Добавил страницу о сайте"

# 5. Отправить на сервер
git push

# 6. Проверить, что всё ушло
git log --oneline -5

Шесть команд — и твои изменения на GitHub. Мышкой то же самое заняло бы минуты три по меню.

Правила безопасности

  • Не копируй команды из интернета слепо. Особенно с sudo в начале.
  • rm -rf опасен. Никогда не пиши его у корня (/) или домашней папки — снесёт всё без вопросов.
  • Не работай под root без нужды. Административные команды — только когда действительно надо.
  • Если не понимаешь команду — гугли. Всегда. 30 секунд поиска спасут систему.

Что важно запомнить

  • Терминал — это быстрее мышкой, а не страшнее.
  • Начни с пяти команд: pwd, ls, cd, mkdir, cat.
  • Tab и стрелка вверх экономят часы.
  • rm -rf не прощает ошибок — будь с ним аккуратен.
