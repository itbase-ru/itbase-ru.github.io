Python с нуля — базовый синтаксис за 15 минут

20 апреля 2026 • 12 мин чтения
Поделиться:

Python — один из самых дружелюбных языков для старта. Читается почти как английский, не требует лишних слов и точек с запятой. В этой статье — весь базовый синтаксис, который нужен, чтобы начать писать код.

Если ещё не выбрал язык — глянь как выбрать первый язык программирования.

Первая программа

Традиционное начало — «Hello, world». В Python это одна строка:

print('Привет, мир!')

print — встроенная функция, которая выводит текст на экран. Запусти этот код в любом онлайн-редакторе (например, replit.com или python.org/shell) — увидишь результат.

Переменные и типы

Переменная — это имя, под которым хранится значение. В Python тип указывать не нужно — он определяется автоматически.

# Строка
name = 'Кирилл'

# Целое число
age = 30

# Дробное число
height = 1.78

# Логический тип
is_student = False

# Проверяем типы
print(type(name))    # <class 'str'>
print(type(age))     # <class 'int'>
print(type(height))  # <class 'float'>
print(type(is_student))  # <class 'bool'>

Основные типы: str (строка), int (целое), float (дробное), bool (True/False), None (пустое значение).

Строки

Строки можно складывать и повторять:

first = 'Привет'
second = 'мир'

# Складываем через плюс
greeting = first + ', ' + second + '!'
print(greeting)   # Привет, мир!

# Повторяем строку
line = '=' * 20
print(line)   # ====================

Длинные тексты можно собирать через f-строки — но об этом ниже.

Условия

Программа умеет принимать решения через if:

age = 20

if age >= 18:
    print('Совершеннолетний')
else:
    print('Ещё рано')

Обрати внимание: в Python нет фигурных скобок. Вместо них — отступы. Всё, что с отступом, — внутри блока.

Можно добавить ещё вариантов через elif:

score = 75

if score >= 90:
    print('Отлично')
elif score >= 70:
    print('Хорошо')
elif score >= 50:
    print('Удовлетворительно')
else:
    print('Надо доработать')

Циклы

Два вида циклов: for и while.

for — когда знаешь, сколько раз

# Пройти по списку
fruits = ['яблоко', 'банан', 'груша']
for fruit in fruits:
    print(fruit)

# Или прогнать числа от 0 до 4
for i in range(5):
    print(i)

range(5) даёт числа 0, 1, 2, 3, 4 — пять штук, не включая 5. Это стандарт.

Полезный вариант — range(1, 6): числа от 1 до 5.

while — пока условие истинно

counter = 0

while counter < 5:
    print('Счётчик: ' + str(counter))
    counter = counter + 1

Важно: не забудь увеличивать счётчик внутри while. Иначе цикл никогда не закончится, и программа зависнет.

Списки

Список — упорядоченный набор значений. В квадратных скобках:

numbers = [10, 20, 30, 40]
names = ['Анна', 'Борис', 'Вера']

# Первый элемент
print(numbers[0])   # 10

# Последний
print(numbers[-1])  # 40

# Длина
print(len(numbers))   # 4

Основные операции:

items = [1, 2, 3]

# Добавить в конец
items.append(4)
print(items)   # [1, 2, 3, 4]

# Удалить по значению
items.remove(2)
print(items)   # [1, 3, 4]

# Проверить, есть ли элемент
print(3 in items)   # True

# Срез — часть списка
print(items[0:2])   # [1, 3]

Срез [0:2] — это «с 0-го по 2-й, не включая 2-й». То есть элементы с индексами 0 и 1.

Словари

Словарь хранит пары «ключ → значение». Идеален для структурированных данных:

user = {
    'name': 'Кирилл',
    'age': 30,
    'city': 'Москва'
}

# Доступ по ключу
print(user['name'])   # Кирилл

# Добавить или изменить
user['email'] = 'kirill@mail.ru'

# Проверить наличие
print('age' in user)   # True

# Пройти по всем парам
for key, value in user.items():
    print(key + ': ' + str(value))

Функции

Функция — блок кода с именем, который можно вызывать сколько угодно раз. Объявляется через def:

def greet(name):
    return 'Привет, ' + name

# Вызов
result = greet('Кирилл')
print(result)   # Привет, Кирилл

Ключевое слово return возвращает значение. Без него функция вернёт None.

Функция может принимать несколько аргументов и иметь значения по умолчанию:

def introduce(name, age=18):
    return name + ', ' + str(age) + ' лет'

print(introduce('Анна'))          # Анна, 18 лет
print(introduce('Борис', 25))     # Борис, 25 лет

Аргумент с = — необязательный. Если его не передать, используется значение по умолчанию.

Импорт модулей

Python идёт с огромной стандартной библиотекой. Подключается через import:

import math
import random

# Используем функции модуля
print(math.sqrt(16))         # 4.0
print(random.randint(1, 6))  # случайное от 1 до 6

Сторонние библиотеки ставятся через pip install имя_пакета. Потом — тот же import.

Практический пример

Соберём всё вместе. Программа, которая считает статистику по списку оценок:

# Список оценок
grades = [5, 4, 3, 5, 4, 5, 4, 3, 5, 4]

# Функция подсчёта среднего
def average(numbers):
    total = 0
    for n in numbers:
        total = total + n
    return total / len(numbers)

# Функция определения категории
def category(avg):
    if avg >= 4.5:
        return 'отличник'
    elif avg >= 3.5:
        return 'хорошист'
    else:
        return 'троечник'

# Основная логика
avg = average(grades)
cat = category(avg)

print('Средний балл: ' + str(round(avg, 2)))
print('Категория: ' + cat)

Запусти — увидишь средний балл и категорию. Это уже настоящая программа, хоть и маленькая.

Что учить дальше

  1. Кортежи и множества. Родственники списков со своими правилами.
  2. Классы и ООП. Об этом — ООП простыми словами.
  3. Работа с файлами. Чтение и запись через open.
  4. Исключения. Обработка ошибок через try и except.
  5. Продвинутые функции. Декораторы, генераторы, лямбды.
Не пытайся выучить всё сразу. Освой базу — переменные, условия, циклы, функции — и напиши 5 маленьких программ. Только потом двигайся дальше.

Итог

Python прост в синтаксисе: нет фигурных скобок, не нужно объявлять типы, код читается как английский. Основные конструкции — переменные, условия, циклы, списки, словари, функции — покрывают 80% задач новичка. Дальше — практика: калькулятор, todo-список, парсер. Реальные задачи учат быстрее любых курсов.
