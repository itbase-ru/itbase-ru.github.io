Декораторы в Python — что это и зачем нужны

19 апреля 2026 • 11 мин чтения
Поделиться:

Декораторы в Python — одна из тех вещей, которые сначала пугают, а потом становятся любимым инструментом. Это способ обернуть функцию в другую функцию, не меняя её код. Разберём по шагам.

Функции — это объекты

Прежде чем понять декораторы, надо запомнить одну вещь: в Python функция — это объект, как число или строка. Её можно:

  • Присвоить переменной.
  • Передать в другую функцию как аргумент.
  • Вернуть из функции.
def greet(name):
    return 'Привет, ' + name

# Присваиваем функцию переменной
hello = greet
print(hello('Кирилл'))   # Привет, Кирилл

# Передаём как аргумент
def call_function(func, arg):
    return func(arg)

print(call_function(greet, 'Анна'))   # Привет, Анна

# Возвращаем из функции
def make_greeter():
    def inner(name):
        return 'Здравствуй, ' + name
    return inner

greeter = make_greeter()
print(greeter('Иван'))   # Здравствуй, Иван

Эта способность — основа декораторов. Запомни её — дальше всё будет логично.

Первый пример: обёртка

Хотим узнать, сколько времени работает функция. Можно вписать замеры прямо в неё, но если функций много — код повторяется.

Лучше написать функцию-обёртку:

import time

def measure_time(func):
    # Внутренняя функция — заменяет исходную
    def wrapper(*args, **kwargs):
        start = time.time()
        # Вызываем исходную функцию со всеми её аргументами
        result = func(*args, **kwargs)
        elapsed = time.time() - start
        print(func.__name__ + ' работала ' + str(round(elapsed, 4)) + ' сек')
        return result
    return wrapper

# Оборачиваем функцию вручную
def slow_sum(n):
    total = 0
    for i in range(n):
        total += i
    return total

slow_sum = measure_time(slow_sum)
slow_sum(1000000)
# Выведет: slow_sum работала 0.0412 сек

Мы заменили slow_sum на wrapper, который внутри вызывает оригинал и добавляет замер времени. Функция работает по-старому, но с новой фичей.

Синтаксис декоратора

Оборачивать руками неудобно. Есть специальный синтаксис — @имя_декоратора над функцией.

import time

def measure_time(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        elapsed = time.time() - start
        print(func.__name__ + ' работала ' + str(round(elapsed, 4)) + ' сек')
        return result
    return wrapper

# То же самое, что slow_sum = measure_time(slow_sum)
@measure_time
def slow_sum(n):
    total = 0
    for i in range(n):
        total += i
    return total

slow_sum(1000000)
# Выведет: slow_sum работала 0.0412 сек

Строка @measure_time — это просто сокращение. Python автоматически применяет декоратор к функции ниже.

Декоратор — это функция, которая принимает одну функцию и возвращает другую. Всё. Ничего магического.

Что значат *args и **kwargs

Внутри wrapper мы не знаем, какие аргументы будут у оборачиваемой функции. Поэтому используем:

  • *args — все позиционные аргументы как кортеж.
  • **kwargs — все именованные аргументы как словарь.
def wrapper(*args, **kwargs):
    # args — кортеж позиционных аргументов
    # kwargs — словарь именованных
    return func(*args, **kwargs)   # передаём все дальше

Это универсальный приём: обёртка работает с любой функцией, независимо от её сигнатуры.

Декоратор с параметрами

Иногда нужно передать настройки в декоратор. Например, «повторять функцию N раз при ошибке».

import time

def retry(attempts):
    # Внешняя функция принимает параметр декоратора
    def decorator(func):
        # Средняя функция принимает саму функцию
        def wrapper(*args, **kwargs):
            # Внутренняя — оборачивает вызов
            for i in range(attempts):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if i == attempts - 1:
                        raise   # последняя попытка — пробрасываем ошибку
                    print('Попытка ' + str(i + 1) + ' упала, пробуем снова')
                    time.sleep(1)
        return wrapper
    return decorator

@retry(attempts=3)
def unstable_request():
    # Тут могла бы быть функция, которая иногда падает
    print('Пробуем выполнить запрос')
    raise ConnectionError('Сеть недоступна')

unstable_request()

Получается три уровня вложенности:

  1. retry(attempts) — принимает параметры декоратора.
  2. decorator(func) — принимает функцию.
  3. wrapper(*args) — принимает аргументы вызова.

С первого раза сложно, но это самый частый паттерн в реальном коде.

functools.wraps — важная деталь

После оборачивания функция теряет свои метаданные: имя, docstring, документацию.

@measure_time
def greet(name):
    'Возвращает приветствие'
    return 'Привет, ' + name

print(greet.__name__)   # wrapper, а не greet!
print(greet.__doc__)    # None, а не 'Возвращает приветствие'

Решается декоратором functools.wraps:

import functools
import time

def measure_time(func):
    @functools.wraps(func)   # сохраняем метаданные
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        print(func.__name__ + ': ' + str(round(time.time() - start, 4)) + ' сек')
        return result
    return wrapper

@measure_time
def greet(name):
    'Возвращает приветствие'
    return 'Привет, ' + name

print(greet.__name__)   # greet
print(greet.__doc__)    # Возвращает приветствие

Всегда добавляй @functools.wraps к своим wrapper'ам. Это привычка хорошего тона.

Где применяются декораторы

Веб-фреймворки

FastAPI, Flask, Django — везде декораторы связывают URL с функцией:

from flask import Flask
app = Flask(__name__)

@app.route('/users')
def get_users():
    return [{'id': 1, 'name': 'Кирилл'}]

# При заходе на /users Flask вызовет эту функцию

Кэширование

import functools

@functools.lru_cache(maxsize=128)
def fibonacci(n):
    if n < 2:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

# Первый вызов для n=50 — мгновенно благодаря кэшу
print(fibonacci(50))

lru_cache — встроенный декоратор. Он запоминает результаты вызовов и отдаёт их из памяти при повторе. Огромное ускорение для рекурсивных функций.

Аутентификация

def require_auth(func):
    @functools.wraps(func)
    def wrapper(request, *args, **kwargs):
        if not request.user:
            raise PermissionError('Нужна авторизация')
        return func(request, *args, **kwargs)
    return wrapper

@require_auth
def delete_post(request, post_id):
    # Попадём сюда только если пользователь авторизован
    return 'Пост удалён'

Логирование

def log_call(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print('Вызов: ' + func.__name__)
        return func(*args, **kwargs)
    return wrapper

@log_call
def process_order(order_id):
    return 'Заказ ' + str(order_id) + ' обработан'

process_order(42)
# Выведет: Вызов: process_order
# Затем: Заказ 42 обработан

Частые ошибки

  • Забыть return func(*args, **kwargs). Тогда оборачиваемая функция не выполнится.
  • Забыть return wrapper. Декоратор вернёт None, и функция исчезнет.
  • Не использовать functools.wraps. Теряются имя и docstring.
  • Путать уровни вложенности. Декоратор без параметров — 2 уровня. С параметрами — 3.

Итог

Декоратор — это функция, которая оборачивает другую функцию. Работает через способность Python возвращать функции из функций. Применяется в фреймворках, кэшировании, аутентификации, логировании. Синтаксис @имя — просто сокращение. Не забывай про functools.wraps и *args, **kwargs. Как только поймёшь декораторы — код станет заметно короче.
