Что такое облако: IaaS, PaaS, SaaS и почему это удобно

5 марта 2026 • 9 мин чтения
Поделиться:

Облако — это не «что-то в небе». Это чужие компьютеры, которые ты арендуешь по требованию. Заплатил за час работы — получил час работы. Не нужен — выключил, деньги больше не тратятся. Звучит просто, но под этим скрывается целая индустрия.

Аналогия с электричеством

Раньше каждая фабрика имела свой генератор. Потом появились электросети — стало дешевле покупать электричество, чем строить генератор у себя. Облако делает то же самое, но с компьютерами:

  • Нужен сервер на 5 минут — арендуй его на 5 минут.
  • Нужно хранить терабайты данных — плати за гигабайты в месяц.
  • Нагрузка выросла в 100 раз на выходных — облако само добавит ресурсы.

Три модели обслуживания

МодельЧто даютТы управляешьПример
IaaSВиртуальные серверы, диски, сетиОС, приложенияAWS EC2, DigitalOcean
PaaSГотовую среду для кодаТолько кодVercel, Heroku, Render
SaaSГотовый сервисНичегоGmail, Notion, Google Docs

Чем ниже уровень — тем больше гибкости и работы. Чем выше — тем быстрее старт, но меньше контроля.

Главные сервисы AWS

AWS — крупнейший облачный провайдер. Вот что используют чаще всего:

СервисЧто делаетАналог из жизни
EC2Виртуальные серверы (компьютеры)Арендованная машина
S3Хранилище файлов любого размераБесконечный жёсткий диск
LambdaЗапуск кода без сервера, только по событиюТакси: вызвал — поехал, не нужен — не платишь
RDSУправляемые базы данныхБД «под ключ» — бэкапы сами
CloudFrontРаздача статики с ближайшего к пользователю сервераCDN

Что такое S3 простыми словами

S3 — объектное хранилище. Это значит: ты кладёшь туда файлы, а не таблицы. Картинки, видео, бэкапы, логи — всё это живёт в S3.

  • Каждый файл доступен по уникальной ссылке.
  • Можно задать публичный доступ или только для своих.
  • Хранит версии файлов, можно откатиться.
  • Платишь за гигабайты хранения и трафик. Первые 5 ГБ — условно бесплатно.

Именно на S3-совместимых сервисах работает множество статических сайтов, включая этот — хотя тут используется бесплатный GitHub Pages.

Serverless: код без сервера

Название обманчиво — сервер есть, просто ты им не управляешь. Ты пишешь функцию, заливаешь её в облако, и она выполняется, когда приходит запрос. Правила:

  • Не выполняется — не платишь.
  • Один вызов = доли секунды работы = копейки.
  • Облако само масштабируется: хоть 10 вызовов, хоть 10 тысяч.
# Минимальная serverless-функция на Python (AWS Lambda)
def handler(event, context):
    name = event.get('name', 'мир')
    return {
        'statusCode': 200,
        'body': f'Привет, {name}!'
    }

Всё. Файл заливается в AWS, привязывается к URL — и функция работает. Ни сервера, ни ОС, ни обновлений.

Когда облако выгоднее своего железа

СитуацияЧто выбрать
Стартап, нагрузка неизвестнаОблако
Резкие пики нагрузкиОблако
Стабильная нагрузка 24/7Своё железо или выделенный сервер
Нужна строгая безопасность данныхСвоё железо
Эксперимент на 2 дняОблако
Долгосрочный проект 5+ летСчитай экономику

Сколько это стоит

Многие пугаются облаков из-за «непредсказуемых счетов». Правда: при правильной настройке это дешевле обычного хостинга. Примерные цены на 2026 год:

  • Минимальная VPS (1 ядро, 1 ГБ RAM) — от 200–500 ₽/мес.
  • Lambda — первые 1 млн вызовов в месяц бесплатно.
  • S3 — около 2 ₽ за ГБ в месяц.
  • Статический сайт на Vercel / Netlify — бесплатно при небольшом трафике.

Опасность одна: если оставить включённый сервер и забыть — счёт растёт. Решение — всегда ставить биллинг-алерты (уведомления при превышении бюджета).

Что важно запомнить

  • Облако = аренда чужих компьютеров по требованию.
  • IaaS — сервер, PaaS — среда, SaaS — готовый сервис.
  • S3 хранит файлы, Lambda выполняет код, EC2 — это сервер.
  • Облако выгодно при нестабильной нагрузке, для пиков и экспериментов.
  • Для стабильной работы 24/7 часто дешевле выделенный сервер.
