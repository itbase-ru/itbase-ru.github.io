Регулярные выражения: практический разбор с примерами

21 марта 2026 • 12 мин чтения
Поделиться:

Регулярные выражения — «страшные символы», которые отпугивают новичков. На самом деле это язык для поиска и проверки текста. Освоишь базовый набор — и сможешь за секунду проверить email, найти все ссылки в тексте или вытащить номер телефона.

Что это такое

Регулярное выражение (regex) — это шаблон, которому должна соответствовать строка. Например, шаблон «три цифры, дефис, две цифры» описывает индекс в формате 123-45.

Regex используется в:

  • Поиске по тексту (Ctrl+F с галочкой «regex»).
  • Валидации форм (проверка email, телефона).
  • Замене и очистке текста.
  • Парсинге логов, данных, HTML.

Базовые символы

СимволЧто означаетПример
.Любой один символa.c — «abc», «aXc»
\dЦифра 0-9\d\d\d — «123»
\wБуква, цифра или _\w+ — «hello_1»
\sПробел, таб, перенос\s+ — « »
[abc]Один из символов[abc] — a, b или c
[^abc]Любой, кроме этих[^0-9] — не цифра
[a-z]ДиапазонЛюбая строчная буква

Кванторы — «сколько раз»

СимволОзначает
*0 или больше раз
+1 или больше раз
?0 или 1 раз (необязательно)
{3}Ровно 3 раза
{2,5}От 2 до 5 раз
{3,}3 или больше раз

Привязки — где искать

  • ^ — начало строки.
  • $ — конец строки.
  • \b — граница слова.

Без них regex найдёт совпадение где угодно внутри строки. С ними — только там, где указано.

Первый пример: проверка телефона

const phone = "+7 999 123-45-67";

// Шаблон: +7, пробел, 3 цифры, пробел, 3 цифры-2 цифры-2 цифры
const pattern = /^\+7 \d{3} \d{3}-\d{2}-\d{2}$/;

console.log(pattern.test(phone));  // true
console.log(pattern.test("89991234567"));  // false

Разбор шаблона:

  • ^ — начало строки.
  • \+ — плюс (экранируем, потому что + — спецсимвол).
  • 7 — цифра 7 и пробел.
  • \d{3} — три цифры.
  • — пробел.
  • \d{3}-\d{2}-\d{2} — три цифры, дефис, две, дефис, две.
  • $ — конец строки.

Пример: email

const emailRegex = /^[\w.-]+@[\w.-]+\.[a-z]{2,}$/i;

console.log(emailRegex.test("user@mail.ru"));       // true
console.log(emailRegex.test("my.name@site.com"));   // true
console.log(emailRegex.test("не-email"));           // false
console.log(emailRegex.test("@no-user.ru"));        // false

Что тут:

  • [\w.-]+ — буквы, цифры, точки, дефисы — один или больше.
  • @ — собака.
  • [\w.-]+ — домен.
  • \. — точка (экранированная, иначе «любой символ»).
  • [a-z]{2,} — две и больше буквы (зона: ru, com, io).
  • Флаг i в конце — не учитывать регистр.

Работа с regex в JavaScript

test — проверить, есть ли совпадение

const regex = /\d+/;
console.log(regex.test("abc123"));  // true
console.log(regex.test("abc"));     // false

match — найти совпадения

const text = "Цены: 100 руб, 250 руб, 999 руб";
const prices = text.match(/\d+/g);

console.log(prices);  // ["100", "250", "999"]

replace — заменить

const phone = "+7 (999) 123-45-67";
// Убираем все символы, кроме цифр
const digits = phone.replace(/\D/g, "");

console.log(digits);  // "79991234567"

\D — «не цифра». Флаг g — заменять все совпадения, не только первое.

split — разделить строку

const csv = "яблоко, груша ,банан,  слива";
const items = csv.split(/\s*,\s*/);

console.log(items);
// ["яблоко", "груша", "банан", "слива"]

Группы и извлечение

Круглые скобки (...) выделяют часть шаблона, чтобы извлечь её отдельно.

const date = "2026-03-21";
const match = date.match(/(\d{4})-(\d{2})-(\d{2})/);

console.log(match[0]);  // "2026-03-21" — всё совпадение
console.log(match[1]);  // "2026"       — первая группа (год)
console.log(match[2]);  // "03"         — вторая группа (месяц)
console.log(match[3]);  // "21"         — третья группа (день)

Частые задачи

Убрать лишние пробелы

const messy = "  Это   строка   с   пробелами  ";
const clean = messy.replace(/\s+/g, " ").trim();

console.log(clean);  // "Это строка с пробелами"

Найти все ссылки в тексте

const text = "Смотри https://example.com и http://test.ru/page";
const urls = text.match(/https?:\/\/[^\s]+/g);

console.log(urls);
// ["https://example.com", "http://test.ru/page"]

Проверить пароль (минимум 8 символов, цифра, буква)

const strong = /^(?=.*[A-Za-z])(?=.*\d).{8,}$/;

console.log(strong.test("qwerty123"));   // true
console.log(strong.test("qwerty"));      // false — нет цифры
console.log(strong.test("12345678"));    // false — нет буквы

Инструменты, которые экономят нервы

Регулярки сложные. Их тяжело писать «в голове». Используй помощники:

  • regex101.com — главный сайт. Вбиваешь regex и текст, он подсвечивает совпадения и объясняет каждую часть шаблона.
  • regexr.com — похожий, чуть проще.
  • debuggex.com — рисует схему работы regex.

Что важно запомнить

  • Regex — шаблон для поиска по тексту.
  • \d — цифра, \w — буква, . — любой символ.
  • Кванторы: * + ? {n} — задают количество повторов.
  • ^ и $ — начало и конец строки.
  • Круглые скобки () — извлечение группы.
  • Флаги: g — все совпадения, i — без учёта регистра.
  • Всегда проверяй шаблон на regex101.com — не пиши наугад.
