Как создать Telegram-бота с кодом

26 марта 2026 • 12 мин чтения
Поделиться:

Telegram-бот — это, пожалуй, лучший способ попробовать реальное программирование. Кода минимум, обратная связь мгновенная, а бот потом может стать полезным инструментом или даже побочным доходом.

В этой статье — пошагово: от создания бота у BotFather до простого рабочего кода на Python. Опыт программирования желателен, но базы из статьи о старте в программировании хватит.

Шаг 1. Получаем токен у BotFather

  1. Открой Telegram, найди @BotFather.
  2. Отправь команду /newbot.
  3. Придумай имя бота — например, «Мой первый бот».
  4. Придумай username — он должен заканчиваться на bot, например myfirst_test_bot.
  5. BotFather пришлёт токен — длинную строку вида 123456789:AA....
Токен — это пароль от бота. Никому не показывай. Если утёк — через BotFather отзови и получи новый командой /revoke.

Шаг 2. Ставим библиотеку

Для Python есть несколько популярных библиотек: pyTelegramBotAPI (telebot), aiogram, python-telegram-bot. Возьмём pyTelegramBotAPI — самая простая для старта.

pip install pyTelegramBotAPI

Если pip не установлен — сначала поставь Python с официального сайта и отметь галочку «Add to PATH».

Шаг 3. Простейший эхо-бот

Создай файл bot.py и вставь код:

import telebot

TOKEN = 'СЮДА_ВСТАВЬ_СВОЙ_ТОКЕН'
bot = telebot.TeleBot(TOKEN)

@bot.message_handler(commands=['start'])
def on_start(message):
    bot.send_message(
        message.chat.id,
        'Привет! Я эхо-бот. Напиши что-нибудь.'
    )

@bot.message_handler(func=lambda message: True)
def on_text(message):
    bot.send_message(message.chat.id, message.text)

bot.polling(none_stop=True)

Запусти:

python bot.py

Открой Telegram, напиши своему боту /start, потом любое сообщение — он ответит тем же текстом. Поздравляю, бот работает.

Что здесь происходит

  • Импорт и токен. Подключаем библиотеку, создаём объект бота.
  • Декоратор message_handler — «ловит» сообщения по условию.
  • commands=['start'] — срабатывает только на команду /start.
  • func=lambda ... — срабатывает на всё остальное.
  • bot.polling() — бесконечный цикл, который проверяет новые сообщения.

Шаг 4. Обработчики команд

Добавим пару полезных команд:

import telebot
import random

TOKEN = 'СЮДА_ВСТАВЬ_СВОЙ_ТОКЕН'
bot = telebot.TeleBot(TOKEN)

@bot.message_handler(commands=['start'])
def on_start(message):
    bot.send_message(
        message.chat.id,
        'Привет! Команды:\n/start — это сообщение\n'
        '/help — помощь\n/coin — подбросить монетку\n'
        '/roll — бросить кубик'
    )

@bot.message_handler(commands=['help'])
def on_help(message):
    bot.send_message(
        message.chat.id,
        'Просто напиши мне что-нибудь — я повторю.'
    )

@bot.message_handler(commands=['coin'])
def on_coin(message):
    result = random.choice(['Орёл', 'Решка'])
    bot.send_message(message.chat.id, result)

@bot.message_handler(commands=['roll'])
def on_roll(message):
    result = random.randint(1, 6)
    bot.send_message(message.chat.id, f'Выпало: {result}')

@bot.message_handler(func=lambda message: True)
def on_text(message):
    bot.send_message(message.chat.id, f'Ты написал: {message.text}')

bot.polling(none_stop=True)

Обрати внимание на \n — это перенос строки. В обычном Python это пишется как \n, но здесь у нас дополнительный уровень экранирования для отображения.

Шаг 5. Кнопки

Кнопки в Telegram бывают двух видов: Reply (внизу, вместо клавиатуры) и Inline (прямо в сообщении). Разберём inline — они гибче.

from telebot import types

@bot.message_handler(commands=['menu'])
def on_menu(message):
    markup = types.InlineKeyboardMarkup()
    btn_yes = types.InlineKeyboardButton(
        'Да', callback_data='yes'
    )
    btn_no = types.InlineKeyboardButton(
        'Нет', callback_data='no'
    )
    markup.add(btn_yes, btn_no)
    bot.send_message(
        message.chat.id,
        'Тебе нравится программировать?',
        reply_markup=markup
    )

@bot.callback_query_handler(func=lambda call: True)
def on_callback(call):
    if call.data == 'yes':
        bot.answer_callback_query(call.id, 'Отлично!')
        bot.send_message(
            call.message.chat.id, 'Так держать!'
        )
    elif call.data == 'no':
        bot.answer_callback_query(call.id, 'Ну ладно...')
        bot.send_message(
            call.message.chat.id,
            'Попробуй Python — обычно заходит.'
        )

Ключевое: у кнопки есть callback_data, а отдельный обработчик callback_query_handler ловит нажатие и реагирует.

Шаг 6. Где запустить бота

Пока бот работает, у тебя включён компьютер — ок для теста. Но чтобы бот работал всегда, нужен сервер.

Варианты:

  1. VPS — от 200–400 ₽ в месяц. Полный контроль, но нужно уметь в Linux.
  2. Бесплатные хостинги — Railway, Render, Fly.io. Для простых ботов хватает.
  3. PythonAnywhere — простой, но ограничен для ботов с polling.
  4. Свой домашний сервер — Raspberry Pi и подобное.

Самый простой путь для новичка: купить VPS за 200–300 ₽, залить туда bot.py, запустить через screen или tmux, чтобы работал после отключения от SSH.

screen -S bot
python bot.py
# Ctrl+A, затем D — отцепиться, бот продолжит работать
# screen -r bot — вернуться к сессии

Шаг 7. Куда развивать

Базовый бот готов. Дальше можно:

  • Подключить базу данных (SQLite вначале) — хранить пользователей, состояния.
  • Сделать FSM — «машину состояний» для диалогов: спросил имя, потом возраст, потом записал.
  • Интегрировать с API — курс валют, погода, новости.
  • Добавить оплату — Telegram Payments или ЮKassa.
  • Разместить в каталогах — @BotList, @StoreBot.

Частые проблемы

ПроблемаПричина
Бот не отвечаетНе запущен скрипт или токен неправильный
Ошибка 401 UnauthorizedТокен устарел или отозван
Ошибка 409 ConflictЗапущено два экземпляра бота
Бот не видит командыКоманды нужно прописать через setcommands у BotFather
Главное правило: не показывай токен никому. Храни его в переменных окружения или отдельном файле .env, не в самом коде, особенно если выкладываешь проект на GitHub.

Итог

Ты прошёл путь от нуля до рабочего бота: получил токен, написал пару обработчиков, добавил кнопки. Дальше — только практика. Придумай маленькую задачу и запили под неё бота: напоминалку, трекер привычек, конвертер валют. Реальная задача учит быстрее любых курсов.
