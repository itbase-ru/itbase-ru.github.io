Массивы и объекты в JavaScript: полный разбор с примерами

9 марта 2026 • 12 мин чтения
Поделиться:

В JavaScript два главных способа хранения коллекций данных — массивы и объекты. Через них проходит 90% всей работы. Разберём подробно: как создавать, читать, менять, перебирать.

Массив — список по порядку

Массив хранит значения в определённом порядке. У каждого значения есть индекс — позиция, начиная с нуля.

const colors = ["красный", "зелёный", "синий"];

console.log(colors[0]);       // красный
console.log(colors[1]);       // зелёный
console.log(colors[2]);       // синий
console.log(colors[99]);      // undefined (такого индекса нет)
console.log(colors.length);   // 3

Важно: нумерация начинается с 0, а не с 1. colors[0] — первый элемент, colors[2] — третий. Это правило номер один, которое новичок забывает.

unshift(x)Добавляет в началоДа

const list = [10, 20, 30];

list.push(40);            // [10, 20, 30, 40]
list.pop();               // [10, 20, 30]
list.unshift(5);          // [5, 10, 20, 30]
list.shift();             // [10, 20, 30]

console.log(list.includes(20));    // true
console.log(list.indexOf(30));     // 2
console.log(list.slice(0, 2));     // [10, 20] — копия
console.log(list.join("-"));       // "10-20-30"

Перебор массива: пять методов, которые нужны всегда

Раньше массив перебирали циклом for. Сейчас есть методы — короче, понятнее, безопаснее.

forEach — пройтись по всем

const nums = [1, 2, 3];

nums.forEach(n => {
  console.log(n * 2);
});
// 2
// 4
// 6

map — превратить каждый элемент

const nums = [1, 2, 3];
const doubled = nums.map(n => n * 2);

console.log(doubled);   // [2, 4, 6]
console.log(nums);      // [1, 2, 3] — исходный не изменился

filter — оставить только подходящие

const nums = [1, 2, 3, 4, 5, 6];
const even = nums.filter(n => n % 2 === 0);

console.log(even);      // [2, 4, 6]

find — найти первый подходящий

const users = [
  { name: "Аня", age: 25 },
  { name: "Борис", age: 30 },
  { name: "Вера", age: 35 }
];

const found = users.find(u => u.age > 27);
console.log(found);     // { name: "Борис", age: 30 }

reduce — свернуть в одно значение

const prices = [100, 200, 300];

const total = prices.reduce((sum, price) => sum + price, 0);
console.log(total);     // 600

Здесь 0 в конце — стартовое значение. sum накапливает результат, price — текущий элемент.

Объект — данные по именам

Объект хранит значения по ключам, а не по индексам. Идеален, когда нужно описать что-то целое: пользователя, товар, настройки.

const user = {
  name: "Аня",
  age: 25,
  city: "Москва",
  hobbies: ["код", "книги"]
};

console.log(user.name);          // Аня
console.log(user["age"]);        // 25 — второй способ
console.log(user.hobbies[0]);    // код

Работа с объектами

const user = { name: "Аня", age: 25 };

// Добавить или изменить
user.city = "Москва";

// Удалить
delete user.age;

// Проверить наличие ключа
console.log("name" in user);   // true

// Получить все ключи или значения
console.log(Object.keys(user));    // ["name", "city"]
console.log(Object.values(user));  // ["Аня", "Москва"]

// Перебрать
Object.entries(user).forEach(([key, value]) => {
  console.log(key + ":", value);
});

Массив объектов — самая частая структура

В реальной работе ты почти всегда работаешь с массивом объектов: список пользователей, товаров, комментариев.

const products = [
  { name: "Клавиатура", price: 3000, inStock: true },
  { name: "Мышь", price: 1500, inStock: true },
  { name: "Монитор", price: 25000, inStock: false }
];

// Найти все товары в наличии
const available = products.filter(p => p.inStock);

// Получить список названий
const names = products.map(p => p.name);

// Найти самый дорогой
const expensive = products.reduce((max, p) =>
  p.price > max.price ? p : max
);

// Посчитать общую стоимость товаров в наличии
const total = products
  .filter(p => p.inStock)
  .reduce((sum, p) => sum + p.price, 0);

console.log(names);       // ["Клавиатура", "Мышь", "Монитор"]
console.log(expensive);   // { name: "Монитор", ... }
console.log(total);       // 4500

Современный синтаксис: деструктуризация и spread

Два приёма, которые сильно сокращают код.

Деструктуризация — вытащить поля в переменные

const user = { name: "Аня", age: 25, city: "Москва" };

const { name, age } = user;
console.log(name);        // Аня
console.log(age);         // 25

Spread — развернуть объект или массив

// Копия массива
const original = [1, 2, 3];
const copy = [...original];

// Склеивание массивов
const merged = [...original, 4, 5];

// Копия объекта с изменениями
const user = { name: "Аня", age: 25 };
const updated = { ...user, age: 26 };

console.log(updated);   // { name: "Аня", age: 26 }
console.log(user);      // { name: "Аня", age: 25 } — исходный не тронут

Что важно запомнить

  • Массив — список по порядку, индексы с нуля.
  • Объект — данные по именам (ключам).
  • map превращает, filter оставляет, reduce сворачивает, find ищет, forEach проходит.
  • Spread ... создаёт копию. Исходные данные не меняются.
  • Деструктуризация экономит строки и делает код читаемее.
  • Массив объектов — самая частая структура в работе.
