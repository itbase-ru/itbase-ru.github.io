Что такое нейросеть: разбор по слоям без формул

15 марта 2026 • 12 мин чтения
Поделиться:

Про нейросети говорят все, но редко кто объясняет, что там внутри. Спойлер: ничего магического. Только числа, умножения и сложения — просто очень много. Разберём по слоям: от одного нейрона до полной сети.

Искусственный нейрон — основа всего

Биологический нейрон получает сигналы, обрабатывает и передаёт дальше. Искусственный делает то же самое, но в виде формулы:

  1. На вход приходит несколько чисел: x₁, x₂, x₃.
  2. Каждое умножается на свой вес: w₁, w₂, w₃.
  3. Результаты складываются, плюс добавляется смещение b.
  4. Полученное число прогоняется через функцию активации.
  5. Результат передаётся дальше.
# Один искусственный нейрон
def neuron(x1, x2, x3, w1, w2, w3, b):
    total = x1*w1 + x2*w2 + x3*w3 + b
    return activation(total)

# Функция активации: превращает любое число в диапазон 0..1
def activation(x):
    # Сигмоида — классический пример
    import math
    return 1 / (1 + math.exp(-x))

Всё. Один нейрон — это буквально одна формула. Сеть состоит из тысяч и миллионов таких нейронов, соединённых в слои.

Что такое веса и смещение

  • Вес — «важность» конкретного входа. Если вес большой, сигнал с этого входа сильно повлияет на результат. Если ноль — вообще не повлияет.
  • Смещение — сдвиг. Позволяет нейрону срабатывать, даже когда все входы нули.

Обучение нейросети — это подбор правильных весов и смещений. Всё, что происходит «внутри магии» — это миллионы подстроек этих чисел.

Три типа слоёв

СлойНазначениеСколько нейронов
ВходнойПринимает данныеСтолько, сколько признаков
СкрытыйНаходит закономерностиОт десятков до тысяч
ВыходнойВыдаёт результатСтолько, сколько классов

Глубокая сеть — та, у которой больше одного скрытого слоя. Отсюда «глубокое обучение». Современные модели вроде GPT имеют сотни слоёв.

Прямой проход — как сеть получает ответ

Данные идут от входа к выходу по слоям. Каждый слой принимает числа из предыдущего, обрабатывает, передаёт дальше. На выходе — итоговый ответ.

# Один слой: принимает список чисел, выдаёт список чисел
def layer(inputs, weights, biases):
    outputs = []
    for i in range(len(biases)):
        total = biases[i]
        for j in range(len(inputs)):
            total += inputs[j] * weights[i][j]
        outputs.append(activation(total))
    return outputs

# Два слоя подряд — уже мини-сеть
def mini_network(x, w1, b1, w2, b2):
    hidden = layer(x, w1, b1)   # первый слой
    output = layer(hidden, w2, b2)  # второй слой
    return output

Прямой проход — это просто проход по слоям. Пока ничего обучающегося, просто вычисления.

Функции активации — зачем они

Без активации вся сеть сводилась бы к одному умножению — сколько слоёв ни добавляй. Активация добавляет нелинейность — без неё сеть не сможет выучить сложные зависимости.

ФункцияДиапазонГде применяется
Sigmoid0 до 1Вероятности
Tanh-1 до 1Скрытые слои (старое)
ReLU0 и вышеСкрытые слои (стандарт)
Softmax0 до 1, сумма = 1Многоклассовая классификация
 
# ReLU — самая популярная: если отрицательное, то 0
def relu(x):
    return max(0, x)

# Softmax — превращает список чисел в вероятности
def softmax(values):
    import math
    exp_values = [math.exp(v) for v in values]
    total = sum(exp_values)
    return [v / total for v in exp_values]

print(softmax([1, 2, 3]))
# [0.09, 0.24, 0.67] — сумма всех = 1

Обратное распространение — как сеть учится

Это самая сложная часть, но идея проста. По шагам:

  1. Сеть получает пример и выдаёт прогноз.
  2. Сравниваем прогноз с правильным ответом — получаем ошибку.
  3. Смотрим, какой вес сколько внёс в эту ошибку.
  4. Чуть-чуть подстраиваем каждый вес в сторону уменьшения ошибки.
  5. Повторяем для следующего примера.

Миллион примеров — миллион подстроек. Постепенно ошибка уменьшается, а сеть «учится». Никакого осознания внутри нет — только числа.

«Обучение» нейросети — это не запоминание фактов, а подгонка миллиона чисел под закономерности в данных.

Мини-сеть на Python: узнаём XOR

Задача XOR — знаменитая проверка: сеть должна выучить правило, где результат 1, если входы разные, и 0, если одинаковые. Одним слоем это невозможно, нужно минимум два.

import numpy as np

# Данные: 4 примера (XOR)
X = np.array([[0,0], [0,1], [1,0], [1,1]])
Y = np.array([[0], [1], [1], [0]])

# Инициализируем веса случайно
np.random.seed(1)
W1 = np.random.randn(2, 4)   # вход (2) → скрытый слой (4)
W2 = np.random.randn(4, 1)   # скрытый (4) → выход (1)

learning_rate = 0.5

# Сигмоида
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_deriv(x):
    s = sigmoid(x)
    return s * (1 - s)

# 10000 циклов обучения
for epoch in range(10000):
    # --- Прямой проход ---
    h_in = X.dot(W1)          # вход скрытого слоя
    h_out = sigmoid(h_in)     # выход скрытого слоя
    o_in = h_out.dot(W2)      # вход выходного нейрона
    o_out = sigmoid(o_in)     # финальный прогноз

    # --- Ошибка ---
    error = Y - o_out

    # --- Обратный проход ---
    d_output = error * sigmoid_deriv(o_in)
    d_hidden = d_output.dot(W2.T) * sigmoid_deriv(h_in)

    # --- Обновление весов ---
    W2 += h_out.T.dot(d_output) * learning_rate
    W1 += X.T.dot(d_hidden) * learning_rate

# Проверка
print("Прогнозы:")
print(o_out.round(3))
print("Правильные ответы:")
print(Y)

После обучения прогнозы сети будут близки к [0, 1, 1, 0]. Формулу XOR никто не вписывал — сеть нашла её сама из данных. Ровно так же, только в миллионы раз сложнее, работают GPT и распознавание лиц.

Что дальше: типы сетей

  • Свёрточные (CNN) — для картинок. Ищут узоры: контуры, формы, лица.
  • Рекуррентные (RNN, LSTM) — для последовательностей: текст, звук, временные ряды.
  • Трансформеры — современный стандарт. Лежат в основе GPT, BERT и почти всех LLM.
  • Генеративные (GAN, диффузионные) — для создания картинок: Midjourney, DALL-E, Stable Diffusion.

Что важно запомнить

  • Нейрон — это умножение + сложение + активация. Всё.
  • Веса — то, что подстраивается при обучении.
  • Слои — для сложных зависимостей. Один слой = слишком просто.
  • Активация добавляет нелинейность. Без неё сеть бессмысленна.
  • Обратное распространение — механизм подстройки весов. Вся «магия» обучения.
  • Никакого понимания внутри нет — только закономерности в числах.
