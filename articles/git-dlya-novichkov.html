Git для новичков: 10 команд, которых хватит в 90% случаев

5 февраля 2026 • 6 мин чтения
Поделиться:

Git — это машина времени для твоего кода. Она сохраняет состояние проекта в любой момент, и ты всегда можешь вернуться назад.

Зачем это нужно

  • Откатить код, если что-то сломал.
  • Работать над двумя версиями проекта одновременно.
  • Работать в команде, не перезаписывая чужие файлы.
  • Видеть, кто, когда и что менял.

Минимум команд

КомандаЧто делает
git initСоздаёт репозиторий в текущей папке
git statusПоказывает, что изменилось
git add .Готовит все изменения к сохранению
git commit -m "текст"Сохраняет изменения с комментарием
git log --onelineСписок всех сохранений
git diffПоказывает, что именно изменилось
git branch имяСоздать отдельную ветку
git checkout имяПереключиться на ветку
git pushОтправить код на GitHub
git pullЗабрать свежие изменения

Рабочий цикл

99% времени ты повторяешь четыре шага:

git status                    # 1. смотрю, что изменилось
git add .                     # 2. готовлю изменения
git commit -m "добавил поиск" # 3. сохраняю с описанием
git push                      # 4. отправляю на сервер

Запомни этот цикл — и ты уже умеешь пользоваться Git на бытовом уровне.

Частые ошибки новичков

  • Забыл git add перед commit. Тогда в сохранение не попадёт ничего.
  • Пишет комментарии типа «фикс». Через месяц не поймёшь, что там было. Пиши по делу.
  • Боится push. Отправка не удалит код — она его опубликует.
  • Хранит пароли в репозитории. Никогда. Ни в каком виде.
