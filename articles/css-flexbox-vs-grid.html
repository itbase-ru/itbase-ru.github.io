CSS: Flexbox против Grid — когда что использовать

22 февраля 2026 • 8 мин чтения
Поделиться:

Раньше верстали таблицами, потом — плавающими блоками (float), а теперь есть два нормальных инструмента: Flexbox и Grid. Оба входят в CSS, оба поддерживаются всеми современными браузерами. Вопрос — когда какой.

Одной фразой

Flexbox — для раскладки в одном направлении (строка или колонка). Grid — для раскладки в двух направлениях (строки и колонки одновременно).

Flexbox: одна ось

Идеален, когда надо расположить кнопки в ряд, центрировать что-то, распределить пункты меню. Ты работаешь с одной осью — горизонтальной или вертикальной, но только одной.

.menu {
  display: flex;
  gap: 16px;               /* отступ между пунктами */
  align-items: center;     /* выравнивание по поперечной оси */
  justify-content: space-between; /* распределение по основной оси */
}

Как это читается:

  • display: flex — включаем flexbox. Дети этого элемента встают в ряд.
  • gap: 16px — отступ между детьми. Не надо никаких margin.
  • align-items: center — выровнять по вертикали по центру.
  • justify-content: space-between — раскидать по горизонтали: первый влево, последний вправо.

Grid: две оси

Grid — это таблица на стероидах. Ты задаёшь строки и колонки, а элементы занимают нужные клетки. Идеален для галерей, дашбордов, макетов «сайдбар + контент».

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
  gap: 20px;
}

Что тут происходит:

  • repeat(auto-fill, ...) — создай столько колонок, сколько влезет.
  • minmax(220px, 1fr) — каждая колонка минимум 220 пикселей, максимум — равная доля свободного места.
  • Строки создаются автоматически. Медиазапросы не нужны.

Именно на этой строчке построена сетка карточек в этом сайте — посмотри в style.css, класс .grid.

Как не ошибиться

  1. Раскладка в линию? Flexbox. Пример: панель кнопок.
  2. Нужна сетка вроде «3 колонки, 4 строки»? Grid.
  3. Не знаешь? Начни с Flexbox. Если через 10 минут понял, что нужны обе оси — переключайся на Grid.
  4. Хочешь сетку, которая сама адаптируется? Grid с auto-fill — самый чистый способ.

Их можно комбинировать: display: grid на контейнере и display: flex на каждой карточке. Ничего не мешает.

Что важно запомнить

  • Flexbox — линия. Grid — плоскость.
  • Свойство gap работает в обоих и заменяет геморрой с margin.
  • minmax(auto-fill, ...) в Grid = адаптив без медиазапросов.
  • Не бойся смешивать. Они не конкуренты.
