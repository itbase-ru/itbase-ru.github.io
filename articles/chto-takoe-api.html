Что такое API за 5 минут: понятное объяснение с примерами

16 февраля 2026 • 7 мин чтения
Поделиться:

Аббревиатура API расшифровывается как Application Programming Interface — «программный интерфейс приложения». Звучит скучно. На практике всё проще, чем кажется.

Аналогия с официантом

Представь кафе:

  • Кухня — это сервер с данными.
  • Ты — это твоя программа.
  • Официант — это API.

Ты не идёшь на кухню сам. Ты говоришь официанту: «Одно кофе и круассан». Он идёт на кухню, передаёт заказ, приносит ответ. API работает точно так же: ты говоришь «дай мне вот эти данные», он передаёт запрос серверу, а тебе возвращает результат в понятном виде.

API — это посредник между твоей программой и чужой системой. Он знает, как правильно задать вопрос и как ответить.

Зачем это нужно

  • Не изобретать заново. Не нужно писать свою погодную станцию — есть API погоды.
  • Не знать устройства. Тебе не важно, на чём написана чужая система. Ты просто общаешься по правилам API.
  • Работать вместе. Приложения связываются друг с другом — Telegram с банком, магазин с курьерской службой.

Как это выглядит технически

Почти всегда API в вебе — это HTTP-запросы. Ты «стучишься» по адресу и получаешь ответ — обычно в формате JSON (это структура данных в виде пар «ключ: значение»).

МетодЧто делаетАналогия в кафе
GETПолучить данные«Покажите меню»
POSTСоздать что-то«Сделайте заказ»
PUT / PATCHОбновить«Замените кофе на чай»
DELETEУдалить«Отмените заказ»

Пример: запрос к API на JavaScript

Возьмём бесплатный публичный API GitHub. Запросим данные о пользователе:

// Отправляем GET-запрос на GitHub
fetch('https://api.github.com/users/torvalds')
  .then(response => response.json())     // превращаем ответ в объект
  .then(data => {
    console.log('Имя:', data.name);
    console.log('Подписчиков:', data.followers);
    console.log('Публичных репозиториев:', data.public_repos);
    console.log('Ссылка на профиль:', data.html_url);
  })
  .catch(error => console.error('Ошибка:', error));

Разберись, что происходит по шагам:

  1. fetch(...) — это и есть запрос к API. Мы «стучимся» на указанный адрес.
  2. .json() — ответ приходит в виде текста, а нам нужен объект. Метод превращает одно в другое.
  3. Второй .then(data => ...) получает уже готовый объект. Из него мы берём нужные поля через точку.
  4. .catch(...) — если интернет пропал или API лежит, мы узнаем об этом, а не упадём молча.

Запусти код в консоли браузера — увидишь реальные данные создателя Linux. Это настоящий ответ от настоящего сервера.

Тот же пример на Python

import requests

# Отправляем запрос
response = requests.get('https://api.github.com/users/torvalds')

# Проверяем, что запрос прошёл успешно (код 200 = ок)
if response.status_code == 200:
    data = response.json()
    print('Имя:', data['name'])
    print('Подписчиков:', data['followers'])
    print('Репозиториев:', data['public_repos'])
else:
    print('Ошибка запроса, код:', response.status_code)

Что важно запомнить

  • API — это правила общения между программами.
  • В вебе API почти всегда = HTTP-запрос + JSON-ответ.
  • Методы GET, POST, PUT, DELETE — четыре кита работы с данными.
  • Многие API требуют ключ (токен) — иначе их используют все подряд.
  • Всегда проверяй код ответа и обрабатывай ошибки.
