JavaScript: переменные и типы данных простыми словами

24 февраля 2026 • 10 мин чтения
Поделиться:

Любая программа — это данные и действия над ними. Прежде чем писать логику, надо понять, как в языке хранятся данные. Это база, без которой дальше двигаться бессмысленно.

Что такое переменная

Переменная — это коробка с именем. Ты кладёшь в неё значение и потом достаёшь по имени.

let age = 25;
let name = "Аня";

console.log(name, age);   // Аня 25

console.log — команда «показать в консоли». Открой консоль браузера (F12 → Console) и вставь код — увидишь результат.

let, const, var

Способов объявить переменную три. Один из них устарел.

Ключевое словоМожно ли менятьКогда использовать
constНет, значение фиксированоПо умолчанию. Почти всегда
letДаКогда значение будет меняться
varДаНе используй. Устаревший

Правило: пока не знаешь, что менять — пиши const. Если потом действительно надо — заменишь на let. Это защита от случайного изменения данных.

Типы данных

В JavaScript восемь типов. Новичку важны пять из них:

ТипЧто этоПример
numberЧисло (целое и дробное, без разницы)42, 3.14
stringСтрока текста в кавычках"привет", 'ok'
booleanПравда или ложьtrue, false
objectНабор пар «ключ: значение»{ name: "Аня", age: 25 }
arrayСписок значений по порядку[1, 2, 3]
undefinedЗначение не заданоlet x;
nullЯвно заданное «ничего»let x = null;

Как это выглядит в коде

const userName = "Аня";          // строка
const age = 25;                  // число
const isStudent = true;          // булево
const hobbies = ["код", "кофе", "книги"]; // массив
const user = {                   // объект
  name: userName,
  age: age,
  hobbies: hobbies
};

console.log(user.name);              // Аня
console.log(user.hobbies[0]);        // код
console.log(user.hobbies.length);    // 3

Строки и подстановка

Соединять строки через плюсы неудобно. Есть современный способ — шаблонные строки с обратными кавычками:

const name = "Аня";
const age = 25;

// старый способ
const oldWay = name + " — " + age + " лет";

// современный
const newWay = name + " — " + age + " лет";

console.log(newWay); // Аня — 25 лет

Работает то же самое, но без громоздких плюсов — читается лучше и легче подставлять выражения.

Приведение типов — где новички спотыкаются

JavaScript — слабо типизированный язык. Он умеет молча превращать одни типы в другие. Иногда это удобно, иногда — источник багов.

console.log(2 + 2);      // 4    (числа сложились)
console.log("2" + 2);    // 22   (строка + число = строка)
console.log("2" - 2);    // 0    (минус превращает строку в число)
console.log("2" * "3");  // 6    (умножение тоже)

Правило: если хотя бы один операнд — строка, а операция — плюс, получится строка. Это ловушка. Всегда проверяй, что внутри переменной действительно число: функция Number(x) превращает строку в число явно.

Что важно запомнить

  • const по умолчанию, let если правда надо менять, var — никогда.
  • Тип определяется значением, а не объявлением.
  • Плюс со строкой превращает число в строку. Это самая частая ошибка новичка.
  • Объекты — для «имя: значение», массивы — для списков по порядку.
  • Открой консоль и играй с кодом — это лучший способ понять.
